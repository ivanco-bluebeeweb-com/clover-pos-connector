# Clover POS Connector — Preparation

**Category:** C46. Restaurant / Hospitality Point-of-Sale (POS)  
**Vendor URL:** https://clover.com  
**Preparation status:** Specification & Architecture Validated  
**API Documentation Reference:** Vendor Primary API Standard

## 1. Product passport
Коннектор **Clover POS** интегрирует платформу Imperal Cloud с официальным API сервиса для автоматизации задач в категории **C46. Restaurant / Hospitality Point-of-Sale (POS)**. Он предоставляет безопасный интерфейс к проверенным операциям вендора без использования синтетических шаблонов.

## 2. Человеческая проблема
Когда **администратор зала** сталкивается с задачей: **прием платежей, учет ресторанных заказов, управление номенклатурой меню и остатками продуктов**, возникает необходимость ручного переключения между интерфейсами, что замедляет работу и увеличивает риск операционных ошибок. Коннектор Clover POS переносит ключевые сценарии управления прямо в экосистему Imperal.

## 3. Роли и права доступа
- **администратор зала, бармен/кассир, бухгалтер заведения**: основные пользователи, управляющие бизнес-процессами.
- **Владелец рабочей зоны / Администратор**: отвечает за подключение коннектора и выдачу доступов.
- **Оператор Imperal**: выполняет действия только в рамках полномочий, разрешенных API-ключом вендора.

## 4. Первичный сценарий и границы
Основной сценарий: `создание заказа -> добавление позиций с модификаторами -> проведение платежа через терминал`.

**Границы применимости:**
- Коннектор не хранит мастер-пароли и учетные данные третьих сторон.
- Любые необратимые или тарифицируемые операции требуют подтверждения.
- Соблюдаются лимиты запросов (rate limits) сервиса Clover POS.
